جرد ستائر أركان الطليعة - ملفات التحديث

مهم:
1) لا تستبدل ملف js/firebase-config.js؛ احتفظ بإعدادات Firebase الموجودة لديك.
2) استبدل index.html و css/style.css و js/main.js بالملفات الموجودة في هذه الحزمة.
3) تأكد أن أسماء المجلدات في GitHub هي بالضبط: css و js (بحروف إنجليزية صغيرة).
4) في Firebase Authentication فعّل Anonymous sign-in.
5) في Realtime Database تأكد أن قواعد القراءة والكتابة تسمح للمستخدمين المجهولين المصرح لهم بالتطبيق؛ لا تجعل قاعدة البيانات مفتوحة للعامة بلا داعٍ.
6) بيانات هذا التطبيق محفوظة تحت المسار inventory/items و inventory/rolls، منفصلة عن تطبيق مقاسات الزبائن ما دام يستخدم مسارًا آخر.

طريقة العمل:
- كتالوج جديد: رقم الكتالوج، ثم أضف عدة صفوف، كل صف رقم اللون وطول اللفة.
- يمكن إضافة لفة لاحقًا إلى كتالوج موجود.
- لا تُعتمد المطابقة إلا إذا تطابق رقم الكتالوج واللون والطول المسجل.
