تطبيق جرد ستائر أركان الطليعة — النسخة الأولية

محتويات المشروع:
- index.html: صفحات التطبيق.
- css/style.css: التصميم البنفسجي والذهبي.
- js/main.js: منطق الأصناف واللفات والجرد والتقارير.
- js/firebase-config.js: إعدادات Firebase التي يجب تعبئتها.
- manifest.json: إعدادات تثبيت الواجهة كتطبيق ويب.

مهم:
1) هذه نسخة مشروع أولية، وليست APK جاهزًا.
2) لن يعمل الحفظ المشترك حتى تضيف إعدادات Firebase الصحيحة وتفعّل Anonymous Authentication.
3) أنشئ مشروع Firebase مستقلًا للمخزون، ولا تستخدم مشروع مقاسات الزبائن.
4) فعّل Authentication > Sign-in method > Anonymous.
5) أنشئ Realtime Database.
6) سجّل تطبيق Web من إعدادات المشروع، وانسخ الإعدادات إلى js/firebase-config.js.
7) يجب نشر الملفات على استضافة HTTPS مثل Firebase Hosting قبل استخدام تسجيل الدخول والمزامنة على الأجهزة.
8) لا تجعل قواعد قاعدة البيانات مفتوحة للعامة. قبل نشر التطبيق على العمال، يجب ضبط قواعد آمنة وتحديد طريقة السماح للمستخدمين المصرح لهم فقط.
9) الأرقام واللفات لا تُضاف تلقائيًا؛ ابدأ بإدخال الأصناف واللفات الفعلية من المحل.
10) هذه النسخة لا تحتوي بعد على إدارة مستخدمين وأدوار وصلاحيات أو سجل تدقيق كامل؛ يجب استكمالها قبل الاستخدام التجاري اليومي.

ملاحظة تقنية:
- Firebase Web SDK يستخدم اتصالًا بالإنترنت.
- النسخة الحالية تعتمد على مصادقة مجهولة لتسهيل الاختبار فقط. لا توزعها على العمال قبل إعداد قواعد آمنة.
